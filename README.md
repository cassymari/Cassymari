## Sobre

Desenvolvedora Full Stack especializada no ecossistema JavaScript, com experiência na construção de aplicações web completas, APIs REST e integração com bancos de dados relacionais e não relacionais.

Atuo desenvolvendo interfaces modernas com React, serviços back-end com Node.js e Express, modelagem de dados com Prisma ORM e persistência utilizando MySQL e MongoDB.

Tenho interesse em arquitetura de software, boas práticas de desenvolvimento e criação de aplicações escaláveis e de fácil manutenção.
